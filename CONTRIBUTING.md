# Contributing to Geek Lagoon / ร่วมพัฒนา Geek Lagoon

Friends and community contributors are welcome! You can help with course ideas, gameplay, visuals, accessibility, translations, bug fixes, or documentation.

ยินดีต้อนรับเพื่อน ๆ ที่อยากช่วยพัฒนาเกม ทั้งไอเดียสนาม ระบบการเล่น ภาพ เสียง การรองรับมือถือ คำแปล การแก้บั๊ก และเอกสาร

## Get started

1. Fork the repository and clone your fork.
2. Install dependencies with `npm install`.
3. Start the local game with `npm run dev`.
4. Run `npm test` and `npm run build` before submitting.

## Propose a change

- For a bug or a larger feature, open an [Issue](https://github.com/prasertsakd/minigolf/issues) first so we can discuss the approach.
- Submit focused Pull Requests against `main`. Describe what changed and how you tested it.
- For visual or interaction changes, include a screenshot or short recording in the Pull Request.
- Keep the 3D course as the dominant screen area and the HUD compact and readable.
- Keep Thai and English interface text aligned, and use original or properly licensed assets.
- Do not include credentials, local secrets, `node_modules/`, or generated `dist/` files.
